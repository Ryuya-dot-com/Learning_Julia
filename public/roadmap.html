L24 モンテカルロ・シミュレーション

「n=20・効果量 d=0.5 の実験、何%有意になる?」——1万回の仮想実験を数秒で回して、検定力分析を自作します。ブートストラップや順列検定への入り口にも。

Julia
using Random, Distributions, HypothesisTests

function power_sim(rng, n, d; nsim = 10_000)
    hits = 0
    for i in 1:nsim
        a = rand(rng, Normal(), n)
        b = rand(rng, Normal(d, 1), n)
        if pvalue(EqualVarianceTTest(a, b)) < 0.05
            hits += 1
        end
    end
    power = hits / nsim
    mcse = sqrt(power * (1 - power) / nsim)
    return (; power, mcse)
end

result = power_sim(Xoshiro(2026), 20, 0.5)
println(round(100 * result.power, digits = 2))
println(round(100 * result.mcse, digits = 2))
▶ 実行結果(Julia 1.12.6)32.93% / MCSE 0.47pt

※ 分布オブジェクト、明示RNG、NamedTupleを組み合わせた「生成→推定→不確かさ」の型です。種だけでなくJulia版・Manifest・生成済みデータも保存し、具体的な乱数列ではなく必要な統計的性質を検証します。

stress境界: 標本数40・120・400と20%・60%・90%の打切り／切断を組み合わせた18条件を各160反復（2,880試行）で測定しました。40件・90%打切りでは通常観測不足が11/160、40件・90%左truncationではOptimが157/160を受理しても23/160が合成真値から破局的に逸脱し、試行全体の95%区間包含率は平均・SDで76.25%・80.62%でした。5開始値が同じ停留点へ収束しても回復を保証しないため、収束flagだけで公開可とは判定しません。

識別・区間gate: 条件数、parameter相関、相対SE、推定選択確率によるdata-only warningを追加しました。閾値決定とseedを分けたholdoutでは破局的逸脱55/55を警告しました。さらに480試行のprofile likelihood pilotでは、90%左truncationのprofile解決率がn=40・120・400で13.75%・48.75%・91.25%と変化しました。解けた試行のcoverageはWaldより改善しても、未解決試行が多い条件を公開可能とは見なしません。

外部妥当性と独立engine: 別の2母数・5種の片側/両側切断・n=40/120の20条件を各120反復しました。片側1,440試行の破局的逸脱62件はすべてwarningで検出できましたが、両側960試行ではfit失敗116件、受理後の破局的逸脱396件のうち143件を見逃しました。SciPy 1.17.1のCensoredData + norm.fitとtruncate + Nelder–Meadによる5照合は負の対数尤度が最大2.1×10⁻⁶差で一致しました。尤度実装の独立一致は確認しましたが、両側識別gateは不合格です。

両側profile screenの再設計: 区間幅の1・2・4倍の広いsource scaleをprofileし、95%尤度比域に残るfitを停止させました。完全未使用の別母数・別seed holdoutで、破局的逸脱の検出は307/446から436/446（97.8%）へ改善し、中央99%保持480試行でwarningは0でした。ただし難条件の正常域fitも1,010件停止し、10件は未検出です。選択後dataだけでは狭い母分布とまれな選択標本を常に区別できないため、閾値を後付けせずdesign metadataを次のgateとします。

選別人数を使う次のgate: 選別前総数と選択数を加えたselection-count likelihoodを、校正・完全未使用holdoutの計2,880試行で比較しました。条件付き解析のfit失敗174・193件、破局的逸脱463・446件に対し、人数情報を使うfitは両matrixとも失敗0・破局的逸脱0でした。ただしWaldのmu coverageは73.96%・73.54%に留まりました。中央10%と非対称50%を各80反復した追加pilotは全480試行でprofile_okとなり、中央10%のmu coverageはWald 38.75%〜50.00%からprofile 93.75%〜95.00%へ回復しました。人数情報は同定を改善しますが、対称で強い選択には非線形な区間法も必要です。

model misspecification gate: 中央10%選択・選別前4,000件を各80反復し、潜在分布family、境界、人数を別々に誤指定しました。LogNormalをNormalとしてfitすると選択率は一致しても、存在しない負値へ平均15.56%を予測し、95%分位点は真値の47.06%でした。TDist(3)の99%分位点も52.07%へ過小評価しました。Normal dataでも境界幅の2倍誤記録でscaleは正しいmetadata fitの1.9745倍、総数の−20%／＋20%誤記録で0.8288倍／1.1589倍へ変化しました。明白な矛盾は入力で停止し、もっともらしい誤記録は感度分析へ残します。

区間report gate: 選別前cohort全体を再生成するparametric bootstrapとprofile・Waldを同じ結果へまとめ、未解決statusと成功率を保持しました。各80 outer反復の別seed confirmationで、中央10%のmu coverageはWald 42.50%・43.75%に対しprofile 95.00%・93.75%、bootstrap 93.75%・91.25%でした。一方bootstrapのsigma coverageは61.25%・71.25%に留まりました。計算成功100%でも校正を保証しないため、automatic_interval = nothingを維持します。

教材化の進捗: 400人から43人を選ぶ具体例、100人中10人の手計算、条件付き密度と人数項の相殺、固定seedのJulia反例、Wald・profile・bootstrapの比較、family・metadata誤指定、未解決status、観測契約、用語集、ヒント付き7問を研究用教材ドラフトへまとめました。31セルの研究用Pluto Notebookへ、観測契約の編集、人数なし／ありfit、三方式の区間、二つの未解決status、LogNormal support反例を接続し、通常Julia実行とPluto本体でerror 0を確認しました。さらに検索・教材catalog非掲載の参加者向けReact previewへ、入力表、fit・区間表、誤りcodeごとの理由と次の行動を移しました。固定合成fixtureだけを配布し、入力保存・telemetry・公開計算APIなしの独立production entryをChromiumで検証します。共有URLは参加者向けP2研究previewです。

  1. 学習課題: 誰の、どの分析上の詰まりを解消し、既存教材のどこから接続するか。

  5. 撤退可能性: 新packageや外部engineが使えなくても、本編の学習経路と既存成果物を壊さないか。
