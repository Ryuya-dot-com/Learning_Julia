L22 モンテカルロ・シミュレーション

「n=20・効果量 d=0.5 の実験、何%有意になる?」——1万回の仮想実験を数秒で回して、検定力分析を自作します。ブートストラップや順列検定への入り口にも。

Julia
using Random, HypothesisTests

function power_sim(n, d; nsim = 10_000)  # nsim回の仮想実験
    hits = 0
    for i in 1:nsim
        a = randn(n)                 # 統制群
        b = randn(n) .+ d            # 実験群(効果量 d)
        if pvalue(EqualVarianceTTest(a, b)) < 0.05
            hits += 1
        end
    end
    return 100 * hits / nsim
end

Random.seed!(2026)                   # 再現性の確保
println("検定力: $(power_sim(20, 0.5)) %")
▶ 実行結果(Julia 1.12)検定力: 32.93 %

※ L11 のドット記法 .+ がここで効いてきます。関数にしておけば n や d を変えて何度でも呼べて、ファイルでもノートブックでもそのまま動きます。この「生成→検定→集計」の型を、STEP 4 以降のすべてのモデルに広げていきます。乱数の結果はJuliaのバージョンによりわずかに変わります。
