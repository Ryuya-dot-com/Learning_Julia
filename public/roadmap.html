L24 モンテカルロ・シミュレーション

「n=20・効果量 d=0.5 の実験、何%有意になる?」——1万回の仮想実験を数秒で回して、検定力分析を自作します。ブートストラップや順列検定への入り口にも。

Julia
using Random, Distributions, HypothesisTests

function power_sim(rng, n, d; nsim = 10_000)
    hits = 0
    for i in 1:nsim
        a = rand(rng, Normal(), n)
        b = rand(rng, Normal(d, 1), n)
        if pvalue(EqualVarianceTTest(a, b)) < 0.05
            hits += 1
        end
    end
    power = hits / nsim
    mcse = sqrt(power * (1 - power) / nsim)
    return (; power, mcse)
end

result = power_sim(Xoshiro(2026), 20, 0.5)
println(round(100 * result.power, digits = 2))
println(round(100 * result.mcse, digits = 2))
▶ 実行結果(Julia 1.12.6)32.93% / MCSE 0.47pt

※ 分布オブジェクト、明示RNG、NamedTupleを組み合わせた「生成→推定→不確かさ」の型です。種だけでなくJulia版・Manifest・生成済みデータも保存し、具体的な乱数列ではなく必要な統計的性質を検証します。
